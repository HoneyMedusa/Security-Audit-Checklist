## Improvements Made
The following improvements were implemented during the audit:

•	Created password for the system

•	Installed pending system updates.

•	Confirmed firewall and antivirus protection were active.

•	Removed unnecessary browser extensions.

## Recommendations for Better Security

To improve system security further:

•	Regularly update software and operating systems.

•	Use strong and unique passwords.

•	Enable two-factor authentication where possible.

•	Avoid downloading files from unknown or suspicious sources.

•	Perform regular system scans with antivirus software.

## Conclusion
The security audit helped identify potential security risks and allowed improvements to be made. By strengthening passwords, enabling firewall protection, and updating software, the system is now better protected against cyber threats. Regular audits should be conducted to maintain strong security.
